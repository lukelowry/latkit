# Border fixtures

Natural Earth 1:50m coastlines and administrative boundaries; public domain.

- `borders.offsets.bin`: little-endian int32 list offsets.
- `borders.points.bin`: little-endian float32 longitude/latitude pairs.

Native model lists of linework, without polygon interiors or holes: what the network's browser check
draws beneath a graph, and what geography's tests read as lines.

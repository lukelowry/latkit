Natural Earth 1:50m coastlines and administrative line boundaries, public domain.

Native model list storage: `borders.offsets.bin` contains little-endian int32 list offsets; `borders.points.bin` contains little-endian float32 longitude/latitude vector items. These fixture assets were extracted once from the repository Natural Earth data; the renderer has no legacy border format or loader. These are lines, not polygon rings with hole or region ownership.

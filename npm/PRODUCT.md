# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Developers trying latkit through hands-on examples.

## Product Purpose

Show the rendering and interaction features of latkit through working examples with editable controls.

## Capabilities and Constraints

Existing TypeScript and Vite examples use the public latkit WebGPU API. Preserve simulations, data, editing, playback, and export capabilities.

## Brand Commitments

Minimal interface, plain names, little descriptive text, shared UI and styles, and examples that use the available window.
